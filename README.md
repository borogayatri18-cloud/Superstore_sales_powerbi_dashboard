# Superstore Sales Power BI Dashboard

## 📊 Project Overview

This project is an interactive Superstore Sales Dashboard created using Microsoft Power BI as part of Internship Task 4.

The dashboard transforms sales data into meaningful visual insights and provides an overview of sales performance, profitability, regional performance, monthly trends, and customer segments.

## 🎯 Objectives

- Analyze overall sales performance
- Track total sales and total profit
- Analyze sales performance by region
- Identify monthly sales trends
- Analyze sales by customer segment
- Present important business KPIs through an interactive dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## 📈 Dashboard KPIs

- Total Sales
- Total Profit
- Profit Margin
- Growth %
- Total Orders

## 📊 Dashboard Visualizations

- Sales by Region
- Total Sales by Month
- Sales by Segment
- Interactive data table
- KPI Cards
